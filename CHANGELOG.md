# Changelog

## Unreleased

First version: iSpindel ingest over HTTP, automatic grouping into fermentations (gap rule, manual close), live graphs,
recipes, hand measurements and timeline events, per-device calibration, CSV/JSON export, scheduled backups, and a
hardened `.deb` with a Proxmox LXC installer.

UI overhaul: drag-to-zoom graphs with range presets and gap breaks, per-window exclude/split, a restructured
fermentation page (headline stats, merged log, action sheets), per-device cards with calibration preview, dashboard
sparklines, hint bubbles instead of explanatory paragraphs, and layouts for phone through 4K.

Event types are now yours to manage: add, rename or remove them in Settings. Renaming relabels events already logged;
removing a type leaves logged events alone.
