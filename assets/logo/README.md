# Logo

The hydrometer is the "i" of iDrometer.

- `idrometer-icon-small.svg`, `idrometer-icon-small-white.svg`: the hydrometer alone, the version designed to scale down.
  Everything below is built from it.
- `idrometer-icon.svg`, `idrometer-icon-white.svg`: the original, taller drawing (hairline outline).
- `idrometer-wordmark.svg`, `idrometer-wordmark-white.svg`: hydrometer plus "Drometer". The outline is thickened
  so it stays visible at small sizes, and the lettering is outlined (Noto Sans Regular, SIL Open Font License) so no
  font is needed.

`internal/web/static/logo.svg` and `favicon.svg` are the in-app versions; they follow the light/dark colour scheme.
